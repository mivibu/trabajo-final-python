# Trabajo Final - Curso de Python 🐍

Este repositorio contiene el proyecto final desarrollado para el curso de programación en Python. El trabajo está dividido en tres ejercicios prácticos que demuestran la progresión desde la lógica de programación y manejo de archivos hasta el desarrollo de una aplicación web completa con el framework Django.

## 📁 Estructura del Repositorio

El proyecto se divide en tres partes principales:

### 1️ Ejercicio 1
* Analisis y filtrado de lectores provenientes de sensores industriales 

### 2️ Ejercicio 2: Catálogo de Productos
Aplicación de consola para la gestión de un catálogo de productos sostenibles.
* **Tecnologías:** Python, manipulación de archivos JSON.
* **Archivos clave:** `catalogo.py`, `catalogo_ecotech.json`.
* **Descripción:** Implementa lectura, escritura y estructuración de datos utilizando el formato JSON para persistencia de información.

### 3 Ejercicio 3: Panel de Sustentabilidad (Django)
Desarrollo de una aplicación web utilizando **Django** (`echotech_proyecto`) enfocada en el monitoreo corporativo.
* **Tecnologías:** Python, Django, HTML, CSS.
* **Módulos principales:** 
  * Aplicación `sustentabilidad` que incluye vistas, servicios y plantillas.
  * Lógica de cálculo de emisiones de carbono según el consumo eléctrico en diferentes plantas (Norte, Sur, Este, Oeste).
  * Panel de control interactivo renderizado a través de plantillas HTML y estilizado con CSS estático.

##  Tecnologías y Herramientas Utilizadas
* **Lenguaje:** Python 3.x
* **Framework Web:** Django
* **Control de Versiones:** Git y GitHub
* **Entorno de Desarrollo:** Visual Studio Code, Git Bash
* **Frontend:** HTML5, CSS3
